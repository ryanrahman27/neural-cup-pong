# Neural Cup Pong

A compact, **playable action-conditioned world model** for an original
fixed-camera **2.5D cup-toss** game: aim, charge power, and throw an arcing ball
at a triangular rack of cups. The engine only makes training data and eval
ground truth — the goal is a match whose frames are **generated by a learned
model**, engine off.

Why cup pong is a good world-model target: a **fixed camera**, a **near-static
scene** (table + cups), and **one small moving ball** with a **ground shadow**
depth cue. Low visual entropy means a **small model (~2–8M params)** has a real
shot at staying controllable and stable over long autoregressive rollouts. Cups
carry a **presence bitmask** and the ball a **3D position** — both are natural
auxiliary-supervision targets that keep the pixels easy. Original art throughout.

> **Status: Phase 1 complete** — deterministic engine, structured state, 2.5D
> renderer (table / cups / ball+shadow / aim reticle / HUD), tests, and
> keyboard aim-and-throw gameplay.

## Quick start

```bash
pip install -e ".[dev]"
python -m neural_cup_pong.play.play_engine --seed 0
python -m pytest
```

Controls: **Left/Right** aim · **Up/Down** power · **Space** throw · **R** reset · **Esc** quit.
The yellow reticle marks the predicted landing point; the bar shows power.

## Environment API

```python
from neural_cup_pong.environment import NeuralCupPongEnv, actions as A
env = NeuralCupPongEnv()
obs, state = env.reset(seed=0)                 # obs: (96,128,3) uint8
obs, state, reward, terminated, truncated, info = env.step(A.make_action(throw=True))
```

- Physics 60 Hz; each `step` = 3 physics steps → ~20 Hz observations.
- Deterministic given a seed. `GameState` = ball xyz + vel, aim, power,
  cups-present bitmask, score, throws, phase; `to_vector()` for the dynamics
  model. Events: throw / cup-sunk / miss / table-bounce / rack-cleared / game-over.
- Fixed-camera 2.5D projection (table-space `x, y-depth, z-height` → 2D), so the
  scene stays a clean, mostly-static function of state.
